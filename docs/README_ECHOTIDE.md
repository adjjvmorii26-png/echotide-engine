# ECHOTIDE ENGINE

**Tidal memory & generative wave substrate**

Echotide Engine models consciousness and memory as tidal processes: wave crystals form in the Reef, pressure and collapse occur in the Abyss, new forms are born at the Crest, and a Choir of Cantors maintains harmonic consensus across the cycle. It continues the lineage of Parallax → Astral Forge → Nebula Archive into fluid, oscillatory dynamics.

## Core Principles

1. **Memory is tidal** — experiences crystallize as wave forms that resonate and decay.
2. **Collapse is generative pressure** — the Abyss does not erase; it transforms.
3. **Birth happens at the Crest** — new patterns emerge from flux under cantor guidance.
4. **Cantors keep the tide in phase** — four agents reach harmonic consensus each cycle.
5. **Erosion leaves recoverable echoes** — nothing is permanently lost.

## Quick Start

```bash
chmod +x engine_boot.sh
./engine_boot.sh
```

Or:

```bash
node crest/crest_flux.js

```
